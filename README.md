# Telegram Config Subscription Builder

این پروژه آخرین ۳۰ کانفیگ ارسال‌شده در کانال تلگرام [@SOSkeyNET](https://t.me/SOSkeyNET) رو
خودکار جمع‌آوری می‌کنه، **کشور سرور هر کانفیگ رو با GeoIP تشخیص می‌ده**، اسم کانفیگ
(remark) رو به پرچم/اسم‌کشور تغییر می‌ده، و به فرمت ساب‌اسکریپشن استاندارد (base64)
تبدیل می‌کنه — قابل استفاده در V2rayNG، NekoBox، Hiddify، v2rayN و مشابه.

## چطور کار می‌کنه؟

1. `main.py` صفحه‌ی پیش‌نمایش عمومی کانال (`https://t.me/s/SOSkeyNET`) رو می‌خونه —
   بدون نیاز به لاگین یا API key.
2. متن هر پیام رو با BeautifulSoup تمیز استخراج می‌کنه (مقاوم در برابر تگ‌های
   تودرتوی تلگرام) و لینک‌های کانفیگ (`vmess`, `vless`, `trojan`, `ss`,
   `hysteria2`, `tuic`) رو با regex پیدا می‌کنه.
3. آخرین ۳۰ کانفیگ رو نگه می‌داره.
4. برای هر کانفیگ، آدرس واقعی سرور رو استخراج کرده، IP رو resolve می‌کنه و با
   سرویس رایگان [ipwho.is](https://ipwho.is) کشورش رو تشخیص می‌ده.
5. اسم (remark) هر کانفیگ رو با پرچم + اسم کشور جایگزین می‌کنه، مثلاً:
   `🇩🇪 Germany` — دیگه اسم‌های شلوغ و تبلیغاتی کانال توی کلاینت دیده نمیشه.
6. خروجی رو در دو فایل ذخیره می‌کنه:
   - `sub/configs_raw.txt` — لینک‌های خام و تغییرنام‌یافته
   - `sub/sub_base64.txt` — همون لینک‌ها base64-شده (فرمت ساب استاندارد)
7. یک GitHub Action (`.github/workflows/update-sub.yml`) هر ۳۰ دقیقه این اسکریپت رو
   اجرا کرده و در صورت تغییر، فایل‌ها رو خودکار کامیت و پوش می‌کنه.

## راه‌اندازی روی گیت‌هاب

1. یک ریپوی جدید بساز و این فایل‌ها رو داخلش آپلود/پوش کن.
2. در تنظیمات ریپو (Settings → Actions → General → Workflow permissions)
   گزینه‌ی **Read and write permissions** رو فعال کن.
3. برو به تب **Actions**، روی وورک‌فلو `Update Telegram Config Subscription`
   کلیک کن و یک بار دستی Run کن (`Run workflow`).
4. لینک ساب‌اسکریپشن نهایی (به‌جای USERNAME/REPO نام خودت رو بذار):

```
https://raw.githubusercontent.com/USERNAME/REPO/main/sub/sub_base64.txt
```

این لینک رو داخل اپ V2ray خودت (مثلا V2rayNG → Import config from URL) وارد کن.

## اجرای محلی (تست)

```bash
pip install -r requirements.txt
python main.py
```

## تنظیمات قابل تغییر (متغیرهای محیطی)

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `TELEGRAM_CHANNEL` | `SOSkeyNET` | نام کانال (بدون @) |
| `MAX_CONFIGS` | `30` | تعداد آخرین کانفیگ‌هایی که برداشته میشه |
| `LABEL_STYLE` | `flag_name` | نحوه نام‌گذاری کانفیگ: `flag` (فقط پرچم)، `name` (فقط اسم کشور)، `flag_name` (هردو) |

## دیباگ

اگه اجرای وورک‌فلو fail بشه (مثلا هیچ کانفیگی پیدا نشد)، فایل `sub/debug_last_run.txt`
اطلاعات دقیقی درباره‌ی صفحه‌ی گرفته‌شده و تعداد پیام/لینک پیدا‌شده ذخیره می‌کنه — این
فایل حتی موقع fail شدن هم کامیت میشه.

## نکات مهم

- این روش فقط برای کانال‌های **عمومی** تلگرام کار می‌کنه.
- تشخیص کشور بر اساس IP سرور مقصده؛ اگه کانفیگ پشت Cloudflare یا یک CDN دیگه باشه،
  ممکنه کشور نمایش‌داده‌شده، کشور نود CDN باشه نه کشور واقعی سرور اصلی.
- سرویس GeoIP رایگانه و محدودیت نرخ داره؛ برای ۳۰ کانفیگ در هر اجرا مشکلی پیش نمیاد.
- هیچ داده‌ی شخصی یا اکانتی در این پروژه ذخیره نمیشه؛ فقط محتوای عمومیِ کانال خونده میشه.
